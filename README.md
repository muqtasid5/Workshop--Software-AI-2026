# Release Manager Agent Workshop
 
## Scenario
 
You are a Release Manager responsible for assessing whether Release 2.4.0 is ready for deployment.
 
The development team has provided a list of open issues and the latest build results.
 
## Your Objective
 
Analyze the release status and produce:
 
1. A summary of release risks.
2. A list of release blockers.
3. A prioritized action plan.
4. A release readiness assessment.
5. A final recommendation: GO or NO-GO.
6. A stakeholder communication draft.
 
## Available Data
 
- openissues.md
- buildstatus.md
 
## Suggested Prompt
 
You are a Release Manager Agent.
 
Review all project information available in this repository.
 
Tasks:
1. Analyze all open issues.
2. Categorize risks by severity.
3. Identify release blockers.
4. Assess release readiness.
5. Recommend GO or NO-GO.
6. Draft stakeholder communication.
